# helper2

`Helpers/helper2` is the planned home for all harness-specific parsing (Codex, Claude Code, Pi, herdr). The app then speaks one protocol, and harness format changes ship as helper updates instead of app updates. It's built for macOS and Linux like the SSH helper, so the same binary can run locally and remotely; today the app uses it only locally.

## Current state

- **Opt-in:** `DISPATCH_HELPER2=1`. `Chat/Helper2Connection.swift` launches the bundled `helper2/darwin-universal serve` and shares one connection across local agents.
- **Protocol:** the `DSPH2` magic, then little-endian frames (`u32 len, u8 kind, u32 id`, ≤ 1 MiB) over stdin/stdout. The Ready frame advertises `hook.normalize` and `session.hook`.
- **Scope:** normalizes Claude/Codex/Pi hook payloads into harness-neutral events (`src/hook.rs`) and tracks per-session state (`src/service.rs`). Decoding a hook grants no attachment or control authority; the caller authenticates the transport.
- **Constraints:** no crate dependencies (own SHA-256 and streaming JSON). Use a nonblocking kqueue/epoll reactor with no polling, and allocate minimally. Every `unsafe` block needs a `SAFETY:` comment (enforced by clippy).
- **Build:** `scripts/build-ssh-helper.py` builds it into `build/helper2-rust` and the app's `helper2/` resources, alongside the SSH helper.

## Rules for new work

- **Session identity comes only from hooks.** Process inspection, cwd, and transcript guessing return wrong sessions and break on harness updates. Subagents and session changes within one PID also defeat them.
  - Hooks must start and run fast.
  - Hook routing: a user-only Unix socket (dir 700, socket 600) for directly launched agents. Under tmux, the hook sets the `@dispatch-harness-session` pane option. herdr has a single socket.
- **Unsolved:** Codex's shared daemon runs every hook in one process with inherited env, so hooks can't identify their agent. `--no-daemon` may disappear, and matching on cwd fails for agents sharing a directory.
- **Transcripts can exceed 500 MB.** Stream-parse and tail them on notification, skipping tool output until requested.
- **Tests:** contract vectors in `tests/*.tsv` are generated by `tests/*-generate.py` from captured harness payloads; `hook-sources.json` pins each harness version and capture hash. Regenerate vectors from new captures; never hand-edit them. Hashes and JSON are checked against Python oracles; `tests/service.py BINARY` checks the protocol.
- **Install:** the helper installs its own hooks and reports every modified file, diff, and backup. It must be auditable and installable on its own. A protocol-version mismatch asks the user to reinstall and links manual instructions.
